Calculadora de Frete

Você só preenche o endereço (nosso, do cliente ou do fornecedor), escolhe o veículo e se é ida e volta. Km, pedágio, velocidade e custo por hora saem sozinhos do sistema.

Para endereços já cadastrados (cliente/fornecedor), o km e o pedágio vêm de dados reais já registrados. Para um endereço novo (digitado), o sistema traz uma estimativa automática — o cálculo de rota exato, tipo Google Maps de verdade com pedágios reais, só é possível depois de conectarmos a uma API de mapas no sistema em produção (isso não roda dentro de um arquivo HTML sozinho).
